# ADR-0020: Answers recorded for OC-7, OC-8, OC-13, OC-14, OC-19 and OC-87

- Status: Interim (answers relayed in chat; the estate owner's own form has not been updated)
- Source: project lead messages in chat, 29 October 2026
- Approver: Muthu Kumar

## Decision

- **OC-7:** a manager or owner approves attendance. No change in behaviour (ADR-0017).
- **OC-8:** Present, Absent, Leave, Off day and Holiday are enough; none to add now. Leave, Off day and Holiday may be switched on in Manage > Setup > Attendance types.
- **OC-13:** variety is master data; a field can have several varieties, added in Masters. No change in behaviour (ADR-0018).
- **OC-14:** more varieties can be added in Masters. What YMG is has not been explained, so the item stays open.
- **OC-19 and OC-87:** tare is set in Masters and pre-filled on the Plucking form, with a default value for all estates. The default weight was not given, and so these stay "answered, meaning unclear". One value for all estates, set in Masters, was then chosen in chat (ADR-0021). No bag weight is assumed.

## Consequences

- The register shows OC-7, OC-8 and OC-13 as confirmed. Recording the go-live gate for a live tenant is still done by the owner in the app (settings.manage).
- Nothing is switched on or changed for production by this record.
